# Deployment Checklist Skill

This skill helps validate that a deployment is ready to go to production. It reviews CI/CD pipeline state, infrastructure prerequisites, and go-live criteria.

## When to Use

Use this skill when the user asks about:
- Whether a release is ready to deploy
- Checking deployment prerequisites or blockers
- Reviewing CI/CD pipeline status before a release
- Production go-live checklists
